# Client data — read this first

**Never enter and read information from any project other than R&D BIM ENGINE.** This applies to Claude and to any other AI working in this repository, and it is there to keep client data out of AI tools.

- Test against live ACC data only in the R&D BIM ENGINE project. Do not open, list the contents of, or read reviews, issues, files, models, members or anything else from any other project or hub, not even to count or compare.
- If a feature cannot be tested in R&D BIM ENGINE (for example because it has no reviews), test it with made-up data in a local copy and say what was not tested against real data. Ask the user to set up test data in R&D BIM ENGINE or to test it themselves; do not use a client project instead.
- If the app is open on another project in the browser, do not read the page. Switch to R&D BIM ENGINE or close the tab.
